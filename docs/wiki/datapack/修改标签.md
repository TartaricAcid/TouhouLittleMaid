女仆模组使用了大量的标签（Tag）来定义物品、方块、实体分类，你可以通过数据包修改或新增这些标签，从而影响女仆模组的部分功能。

这些标签在 1.20.1 Forge、1.21.1 NeoForge 的游戏中均可使用。

## 物品标签

::: table

|                        标签名称                        |                                     说明                                     |
|:--------------------------------------------------:|:--------------------------------------------------------------------------:|
|    `touhou_little_maid:maid_eat_blocklist_item`    |                           女仆进食黑名单，在此名单下的食物女仆不会进食                           |
|  `touhou_little_maid:maid_mending_blocklist_item`  |        物品拥有经验修补后，女仆在吸收经验或者 P 点时能够进行修复；<br>但是部分物品不能这么做，可将其加入此 tag 下         |
|        `touhou_little_maid:maid_tamed_item`        |         能够驯服女仆的物品，默认已经把所有带有 `#forge:cakes` 和 `#c:cakes` 标签的物品加入其中了         |
| `touhou_little_maid:maid_vanishing_blocklist_item` | 女仆和玩家类似，在穿戴拥有`消失诅咒`附魔的装备（或者饰品）后死亡，其对应的物品会直接消失；<br>但是部分物品不能这么做，可将其加入此 tag 下 |

:::

## 方块标签

::: table

|                      标签名称                      |                          说明                          |
|:----------------------------------------------:|:----------------------------------------------------:|
|       `touhou_little_maid:altar_pillar`        | 在修建祭坛时，可以当做祭坛柱子材料的方块；<br>默认已经包含 `#minecraft:logs` 标签 |
|        `touhou_little_maid:altar_torii`        |                 在修建祭坛时，可以当做祭坛鸟居部分的方块                 |
| `touhou_little_maid:maid_jump_forbidden_block` |   女仆有时候会在一些不该触发跳跃逻辑的方块上反复尝试跳来跳去，故添加此标签来将一些方块放入黑名单中   |

:::

## 实体标签

::: table

|                        标签名称                        |                                   说明                                    |
|:--------------------------------------------------:|:-----------------------------------------------------------------------:|
|    `touhou_little_maid:maid_fairy_attack_goal`     |                          女仆妖精的攻击目标，默认仅攻击铁傀儡和玩家                          |
| `touhou_little_maid:maid_vehicle_rotate_blocklist` | 女仆在骑乘时，为了朝向一致，会强制同步女仆朝向和当前骑乘实体朝向；<br>但是部分模组（如机械动力）这么做反而会导致女仆异常旋转，故添加此标签 |

:::
