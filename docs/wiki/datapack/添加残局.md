在车万女仆 1.4.2 及更高版本中，你可以在制图师小屋、要塞的图书馆的战利品箱子里找到残局道具。

当然，你可以通过数据包添加更多残局。<Plot>通过残局轻松战胜女仆！</Plot>

::: tip 路径说明

残局道具有三种，分别对应五子棋、国际象棋和中国象棋。

它们的文件路径固定，分别为：

- `data/touhou_little_maid/board_states/chess.json` （国际象棋）
- `data/touhou_little_maid/board_states/gomoku.json` （五子棋）
- `data/touhou_little_maid/board_states/xiangqi.json` （中国象棋）

数据包在读取时，会将所有数据包中所有的残局数据合并在一起。

:::

```json5
[
  {
    // 标签，用来区分获取方式或者其他设计辅助用
    "tags": [
      // 目前仅有 library 一种标签，表示该残局可以在制图师小屋、要塞的图书馆的战利品箱子中获取
      "library"
    ],
    // 用于残局道具的名称显示
    "display": {
      // 显示名称的语言文件 key
      "description": "board_state.touhou_little_maid.chess.default",
      // 作者信息，会显示在道具的文本提示里
      "author": "Stockfish"
    },
    // 棋局数据，后面会详细说明如何获取这些数据
    "data": "8/8/2k5/8/8/5NB1/4K3/8 w - - 0 1",
    // 随机选中此残局的权重
    "weight": 1
  }
]
```

## 中国/国际象棋残局数据格式

对于国际象棋或者中国象棋残局，数据部分是使用 [FEN](https://en.wikipedia.org/wiki/Forsyth%E2%80%93Edwards_Notation)
格式来表示棋局状态。

你可以通过一些软件来导出 FEN 棋局数据：

- 象棋巫师（中国象棋）：<https://www.xqbase.com/>
- Chess Wizard（国际象棋）：<https://www.chess-wizard.com/>

## 五子棋残局数据格式

由于五子棋并没有一个通用的标准数据格式，因此车万女仆使用了自创的格式来记录棋局数据。

你可以在游戏内，在处于创造模式的情况下，使用木棍右击五子棋棋盘手动放置棋局。然后使用木棍右击棋盒子来导出当前棋局数据。
