女仆在日常情况下会随机在头顶显示聊天气泡，在 1.4.2 及以后版本中还能够显示表情包。你可以通过**资源包**来添加更多表情包图片。

::: tip 路径说明

标签包图片文件应放置在资源包的 `assets/<任意资源域>/textures/chat_bubble/maid_emoji/` 目录下。

文件名可以自定义，但建议使用小写英文字符与下划线命名以避免兼容性问题。

支持的图片格式为 `PNG` 和 `GIF` 动态图。

:::

::: file-tree

- assets
    - <your_resource_domain> 任意资源域均会被识别
        - textures
            - chat_bubble
                - maid_emoji
                    - happy.png 普通名称的文件会在游戏内强制按照 24x24 像素显示
                    - angry.gif 支持 GIF 动态图
                    - sad-48x48.png 使用 `-宽度x高度` 命名格式的文件会以指定尺寸显示
                    - wow-128x128.gif
                    - ... 图片大小没有限制，但是游戏内显示的尺寸最大为 128x128 像素

:::
