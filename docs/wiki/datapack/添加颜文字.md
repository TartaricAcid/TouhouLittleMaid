女仆在日常情况下会随机在头顶显示聊天气泡，其中包含颜文字。你可以通过数据包来添加更多颜文字。

::: tip 路径说明

该文件固定为 `data/touhou_little_maid/chat_bubble/kaomoji.json`，它会将所有数据包中加载的颜文字合并在一起。

:::

```json5
{
  // 任何情况下都会显示的颜文字
  "core": [
    "(๑>◡<๑)",
    "(｡•̀ᴗ-)✧",
    "(⁄ ⁄•⁄ω⁄•⁄ ⁄)⁄",
    "(๑˃̵ᴗ˂̵)ﻭ✧"
  ],
  // 工作日程时会显示的颜文字
  "work": [
    "( ≧Д≦)",
    "(눈_눈)",
    "〒.〒",
    "(☉_☉)"
  ],
  // 休息日程（指的是不工作也不睡觉时的那个休息啊）时会显示的颜文字
  "idle": [
    "^_^",
    "(╬ Ò ‸ Ó)",
    "(≧▽≦)",
    "(⁎˃ᆺ˂)"
  ],
  // 说梦话，即睡觉时会显示的颜文字
  "sleep": [
    "(¦3[▓▓]",
    "(￣o￣) . z Z",
    "(-_-)zzz",
    "(＝＿＝)～Zzz",
    "(。-ω-)zzz"
  ],
  // 在女仆受伤时会显示的颜文字
  "hurt": [
    "˃ʍ˂",
    "✖‿✖",
    "(╥﹏╥)",
    "(>_<)"
  ]
}
```
