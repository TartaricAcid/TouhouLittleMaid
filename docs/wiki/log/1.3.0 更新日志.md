## 更贴合原版⻛格的修正改动

- 女仆模组的所有实体模型、方块实体模型（包括但不限于女仆妖精、祭坛、背包等）现在都可以通过资源包进行修改了
- 妖精女仆的可攻击目标现在可以通过数据包修改了
- 神龛在创造模式下可以忽略复活条件
- 绀珠之药不能附加消失诅咒和经验修复附魔
- 消失诅咒现在可以作用于女仆，但是受 `keep inventory` 规则影响
- 普通经验修复女仆主副手、护甲栏和饰品栏、P 点修复全部装备
- 潮涌核心现在也能够对女仆起作用了
- 添加 HanakazeT8 制作的的酒狐画
- 大幅度修改女仆战利品项目：
    - 现在很多地方都能生成女仆的各种物品了
    - 大大减少神龛的生成概率
    - 降低 P 点的生成概率
    - 给特定物品打上稀有标签

## 美术资产更新

- 更新 @kang 制作的新版美术内容，并提供内置资源包可以切换新旧两套资源
- 添加西方 project 的模型
- 更新新作模型和爱丽丝的玩偶模型
- 添加更多酒狐、纸板狐、海螺模型
- 优化蛋糕盒机制：
    - 动画更加流畅了
    - 蛋糕盒掉落物现在数据包化了
    - 蛋糕盒会自动拆掉，并有粒子效果
- 优化祭坛设计
    - 祭坛的鸟居和御柱部分材料可以通过数据包修改了
    - 祭坛的御柱上的物品添加了动画效果
    - 祭坛有激活成功和取消激活的音效了
