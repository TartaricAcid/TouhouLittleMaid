## AI 系统优化

- 通信协议升级：改用 HTTP 1.1 进行 AI 对话通信，解决部分站点不支持 HTTP 2.0 导致的连接错误（#833）
- 上下文处理优化：优化 AI 历史对话上下文发送逻辑，避免首句为 tool role 导致的 500 错误
- 掉落物检测优化：女仆收菜时会智能检测工作范围内掉落物数量，当超过 8 个时自动停止工作并提示，防止掉落物过度堆积
- 检索性能提升：优化女仆检索周围掉落物的算法，服务器性能消耗减少约 3%

## 功能增强

### ⼥仆墓碑系统优化

感谢贡献者：[QiChenSn](https://github.com/QiChenSn)

- 智能提示：当玩家背包容量不足时，会给出明确的提示信息
- 强制取回：支持 Shift + 点击无视容量限制强制取回物品

### 扫帚⻜⾏系统重制

- 操控体验优化
    - 大幅减少扫帚惯性，降低上下晃动幅度，显著提升操控便捷性
    - 优化碰撞检测，解决骑乘时碰头卡入方块的问题
- 控制方式改进
    - 空格键和 Shift 键控制垂直上升/下降
    - 脱离扫帚快捷键改为 C 键，避免误触导致坠机
- 功能性提升
    - 女仆不在扫帚上时，玩家仍可按 E 键打开背包
    - 支持速度效果加成，玩家拥有速度效果时扫帚同步提速
    - 骑乘状态下切换女仆工作模式不会导致女仆脱离扫帚
- 开发者支持：新增扫帚控制接口，便于其他模组集成（注意：不兼容旧版 Maid Useful Task 模组）

### 新增内容

- 彩色床系统（感谢 @kang）
    - 新增 6 种颜色床铺：白、黑、黄、蓝、绿、紫（粉色为原色）
    - 支持使用对应染料为床铺染色
- 命令扩展
    - `/tlm maid <maid> no_ai true/false`：控制女仆 AI 开关，设为 true 时女仆保持静止
    - `/tlm maid <maid> xp <count>`：直接设置女仆经验值

## Bug 修复

- 将 yaml 修改为 shadow 打包并 relocate，避免与其他模组导致的包名冲突问题
- 神龛系统修复：解决神龛存储与同步问题，胶片存放不再出现异常（感谢：[QiChenSn](https://github.com/QiChenSn)）
- 背包兼容性：修正坐垫右击船时物品不消耗的问题
- 配置界面稳定性：修复游戏内女仆配置界面崩溃问题
- 动画与姿态：修正女仆从水中上岸到坐垫或船时仍保持游泳姿势的问题
- 采蜜系统：修正采蜜模式下错误从空气中获取 honey level 的问题
- 属性保持：修正女仆死亡后部分药水属性异常消失的问题
- Inventory Tweaks - ReFoxed：修正刷物品 bug
- 思索模组（Ponder）：支持查询祭坛摆放规则
- 精妙背包：装有经验泵和储罐的背包可右击提取女仆经验
- 森罗物语：通过新的 `ISpecialCropHandler` 接口支持水稻收获（需手动种植）
- 攻击保护：女仆投掷的雪球不会被生物（如铁傀儡）攻击
