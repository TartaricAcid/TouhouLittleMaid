## 新增内容

### 零食柜

- 零食柜本身提供 27 格存储空间
- 上方摆放方块类食物时，会渲染两种类型的橱窗

### 女仆偷吃机制

- 女仆现在会在特定方块上摆放自己背包内的食物
- 女仆现在会偷吃特定方块上摆放的食物
- 支持的方块：
    - 女仆模组的零食柜
    - 森罗物语厨房的全部餐桌
- 支持偷吃的食物来源：
    - 原版蛋糕
    - 森罗物语厨房的方块类食物
    - `[JMC] 只是更多的蛋糕！`的蛋糕（还会应用部分效果）
    - 农夫乐事的方块类食物：包括盛宴类食物和三种派，可能兼容部分附属

### 魂符主人检查机制

- 初始魂符现在会绑定玩家
- 主人不符时会给予相应提示信息

### 新增女仆属性

全面整合 Maid Attributes 模组的女仆属性，现在可调节更多属性内容（默认无修改）。感谢 `墨染琴弦`

|                        ID                         |    名称     |                    说明                    |
|:-------------------------------------------------:|:---------:|:----------------------------------------:|
|  `touhou_little_maid:maid_crossbow_attack_speed`  |  女仆弩射击速度  |               女仆使用弩射击的速度倍率               |
|    `touhou_little_maid:maid_gun_attack_speed`     | 女仆枪械射击速度  | 女仆使用枪械（TaCZ/卓越前线）射击的速度倍率（可能无法超越枪本身的最大射速） |
| `touhou_little_maid:maid_passive_use_shield_tick` | 女仆举盾持续时间  |               女仆单次举盾的持续时间                |
|      `touhou_little_maid:maid_pickup_range`       |  女仆拾取范围   |            女仆拾取掉落物/经验球/P 点的范围            |
|     `touhou_little_maid:maid_shoot_cooldown`      |  女仆射击冷却   |            女仆单次射击（弓、弩）后的冷却时间             |
|    `touhou_little_maid:maid_trident_cooldown`     | 女仆三叉戟射击冷却 |             女仆射出一支三叉戟后的冷却时间              |
|     `touhou_little_maid:maid_use_item_speed`      | 女仆物品使用速度  |               女仆使用物品的速度倍率                |
|         `touhou_little_maid:maid_hunger`          |   女仆饱食度   |            本体暂无使用，可供其他模组兼容使用             |

- 女仆近战攻击现在受武器攻击速度影响
- 玩家打开女仆 GUI 的距离现在受 `entity_reach` 属性影响

### 寻路传送方块黑名单

添加女仆寻路传送方块黑名单机制，可有效避免女仆传送、寻路到危险方块上面。感谢 `炜尔` 帮忙添加

目前已添加以下模组的危险方块：

- 机械动力：动力锯、粉碎轮
- 机械动力附属：铁丝网
- 黄蜂领域：重力空气、风力空气
- 农夫乐事：炉灶
- 暮色森林：树篱、炽热方块、骑士金属块
- Alex 的洞穴：原始岩浆
- 通用机械：聚变反应堆框架、超临界移相器外壳
- 沉浸工程：铁丝网
- 铁魔法：火堆、灵魂火堆
- 刷怪塔实用设备：锥刺、研磨机

### 铁魔法动画兼容

### 饰品（Curios）模组兼容

- 添加配置项，可选择性禁用 Curios 兼容
- 饰品模组仅保证不导致游戏崩溃等严重问题，不保证可用性
- 目前测试了四十多个相关模组，暂未发现崩溃问题。感谢 `炜尔` 帮忙测试
- 公示链接：[【腾讯文档】女仆模组 Curios 类相关模组兼容情况表](https://docs.qq.com/sheet/DSnFYbVFxQnpWSGhU?tab=BB08J2)

## 优化改进

### 女仆 AI 对话优化

感谢 `Minner2018`

- 函数调用功能现在默认开启，女仆能更好地理解并执行玩家的指令
- 优化了指令执行逻辑，避免重复执行相同的操作
- 通过 AI 对话切换工作模式时，现在支持在所有工作模式中切换（而非仅限攻击模式），并会自动选择正确的道具
- 新增通过对话切换跟随状态的功能
- 提高了女仆对玩家指令的识别准确率

- 祭坛构建检查更加宽松，现在只要点击中间两个羊毛方块，任意朝向都可以构建
- 启用实体持久化，可能解决难以复现的女仆实体丢失问题
- 女仆现在不会受到浆果丛的伤害（但仍会规避）
- 现在御币的耐久从 300 点增加至 1200 点
