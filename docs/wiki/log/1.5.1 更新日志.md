## AI Agent 更新内容

本次对女仆 AI 聊天功能进行了大幅重构，参照当前主流 Agent 架构设计理念进行了系统性优化。当前仅**车万女仆：纸短情长**附属模组存在兼容性崩溃问题，其余模组兼容正常。

### 站点支持更新

- 阿里云、硅基流动、OpenAI 等站点的模型已更换为最新版
- 移除腾讯混元站点
- 新增以下默认站点：
  - Gemini
  - Grok
  - OpenRouter
  - GLM
  - MiniMax（同时支持 LLM 与 TTS）
  - KiMi
  - 腾讯云（仅支持 ASR 语音识别）

### UI 交互改进

本次大幅降低了 AI 相关功能的配置门槛，显著提升了操作便捷性。

- 所有 AI 聊天相关功能已统一迁移至对着女仆按 **T 键**弹出的 UI 面板中进行配置，原女仆 GUI 中的对应标签页已移除
- 该 UI 面板包含：站点设置、女仆人设提示词编辑、历史聊天记录查看与删除、LLM / TTS / 语言选项、站点配置等功能模块
- 面板中实时显示当前 Token 累计使用量
- 站点配置新增鉴权机制，充分考虑了单机、局域网联机、服务器主机与客机等多种部署场景，服务器管理员无需担心密钥与配置的安全性问题
- 站点配置现已支持完全在游戏内修改，无需手动编辑 JSON 配置文件
- 聊天输入框支持通过上下方向键快速调用历史输入记录，便于二次修改
- TTS 站点选择新增"无"选项，允许玩家在客户端侧主动关闭语音合成功能

### AI 聊天功能重构

- **提示词优化**
  - 女仆现能更准确地识别玩家意图并正确调用对应工具
  - 每次对话时自动注入与当前情境高度相关的上下文，提升指令识别效率

- **对话鲁棒性提升**
  - 当大模型出现幻觉、错误调用工具时，系统将自动触发重试机制，引导模型自主修正
  - 对话前对历史消息结构进行合法性校验，避免通信时出现 HTTP 400 错误（此前在使用 DeepSeek 等模型时频繁触发）
  - 当关联女仆实体不存在时，对话会话将立即终止，防止异常调用

- **缓存命中率优化**（提升缓存命中率可有效降低 API 调用费用并加快模型响应速度）
  - 对话缓存命中率由原先约 50% 提升至约 85%

- **工具调用调整**
  - 新增更多可调用工具，包括：切换女仆坐下、Home 模式、工作日程、设定攻击目标等
  - 增加工具调用链的最大轮次上限，并引入多处熔断机制，在支持 AI 组合调用多个工具完成复杂操作的同时，防止无限循环调用导致 Token 异常消耗
  - 部分内容较丰富的游戏上下文现改由工具调用机制按需获取，降低基础 Token 占用
  - 使用指令 `/tlm ai_chat context` 可输出当前所有可获取的游戏上下文信息
  - 使用指令 `/tlm ai_chat tool` 可输出当前所有可用工具列表

- **Skill 机制**
  - 新增 Skill 机制：可在配置文件夹或数据包的指定路径下放置标准 Skill 文件，系统将在适当时机将其注入对话上下文
  - 内置一个默认 Skill，包含女仆模组本身的相关知识，使女仆能够正确回答有关本模组的问题
  - 使用指令 `/tlm ai_chat skill` 可输出当前所有已加载的 Skill 列表

- **上下文压缩**
  - 当对话历史达到一定长度时，系统将自动对历史记录进行压缩摘要，在保留对话连续性的同时有效降低 Token 占用

- **UI 提示优化**
  - 女仆执行工具调用时，聊天气泡将实时刷新显示当前工具调用状态，减少玩家等待时的困惑
  - 调整普通文本聊天气泡的最大宽度，避免单行内容过长影响可读性

## FallbackIngredient

新增 `FallbackIngredient` 合成素材类型，用于在多模组环境下实现差异化的合成输入（设计思路类似于无尽贪婪终极合成台的多模组适配方案）。

该素材类型会按顺序遍历 `fallbacks` 列表，选取首个已安装模组所对应的素材条目作为实际合成输入，从而实现"若安装了 A 模组则使用 A 的物品，否则回退到 B"的兼容逻辑。

**使用示例：**

以下配方演示了一个祭坛配方，当安装了 `kaleidoscope_cookery` 模组时使用其磨石，否则回退至原版木板作为合成素材，同时必须提供钻石作为固定素材：

```json
{
  "type": "touhou_little_maid:altar_recipe",
  "output": {
    "item": "touhou_little_maid:bookshelf",
    "count": 1
  },
  "power": 0.1,
  "ingredients": [
    {
      // 类型参数，必填
      "type": "touhou_little_maid:fallback_ingredient",
      // 有序列表，按顺序遍历，首个已安装模组对应的条目将作为实际输入素材
      "fallbacks": [
        {
          // 当 kaleidoscope_cookery 模组存在时，使用其磨石
          "modid": "kaleidoscope_cookery",
          "value": {
            "item": "kaleidoscope_cookery:millstone"
          }
        },
        {
          // 回退方案：使用原版木板（标签匹配）
          "modid": "minecraft",
          "value": {
            "tag": "minecraft:planks"
          }
        }
      ]
    },
    // 固定素材：钻石（原版 Ingredient 写法）
    {
      "tag": "forge:gems/diamond"
    }
  ]
}
```
