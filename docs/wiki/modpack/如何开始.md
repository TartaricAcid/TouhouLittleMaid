车万女仆添加了许多其他模组的联动内容，同时还支持 KubeJS 模组的脚本拓展，你可以将其制作成整合包，并通过脚本或配置等实现部分功能的自定义。

## KubeJS 支持

[KubeJS](https://www.curseforge.com/minecraft/mc-mods/kubejs) 是一款允许你通过 JavaScript 脚本来修改游戏内容的模组。车万女仆对 KubeJS 提供了相当完善的支持，包括：

- **祭坛合成**：通过脚本添加或修改祭坛合成配方，甚至可以通过合成直接召唤实体
- **事件系统**：监听女仆的交互、受伤、工作模式启用等事件，并执行自定义逻辑
- **注册饰品**：将任意物品注册成女仆饰品，并自定义装备、卸下、受伤时的回调
- **自定义工作模式**：注册全新的女仆工作模式，包括近战攻击、远程攻击、种田、走向方块/实体等多种预设模板

::: tip 版本说明
本章节的所有内容均同时提供 **1.20.1 Forge** 和 **1.21.1 NeoForge** 两个版本的示例，两者之间存在若干 API 差异，请注意区分。
:::

::: warning 前置要求
在开始之前，请确保你的整合包中已安装 **KubeJS** 模组，版本需与对应的 Minecraft 版本匹配。
:::
