车万女仆（Touhou Little Maid) 是一个 Minecraft Java 版 Forge/NeoForge 模组，灵感来源于 [Little Maid Mob](https://github.com/MMM666/littleMaidMob) 模组和 [东方 Project](https://zh.wikipedia.org/wiki/%E6%9D%B1%E6%96%B9Project)。

这个模组为 Minecraft 添加了可爱的女仆，她们可以帮助玩家战斗、耕种或者完成其他各种各样的任务。

本模组支持基岩版实体格式的模型和动画，你可以轻松切换女仆模型，或创建自己的女仆模型。

本模组还拥有丰富的接口和事件，方便其他模组进行扩展和兼容。
